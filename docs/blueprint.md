# **App Name**: Mawashi Manager

## Core Features:

- Login Page: Login page for secure access control.
- User Management: User management page for managing user accounts and roles.
- Barns Management: Barns management page to oversee barns locations.
- Livestock Overview: Livestock overview page displaying all animals and their locations with filtering
- Expense Tracking: Expense tracking page for monitoring expenses.
- Livestock Purchase: Livestock purchase management for adding new animals and associating them with barns.
- Livestock Sales: Livestock sales page for selling animals, including options for deferred payments.

## Style Guidelines:

- Primary color: Deep Indigo (#4F3A65) for a professional and trustworthy feel.
- Background color: Very light lavender (#F5F3F7).
- Accent color: Muted Gold (#B8860B) to highlight important actions and data points.
- Body and headline font: 'Inter' (sans-serif) for a modern and readable interface.
- Consistent and professional icon set (using, for example, Phosphor Icons) for quick visual understanding of functions.
- Clean and structured layout with clear sections for each area (login, users, livestock, etc.).
- Subtle transitions and animations to enhance user experience when navigating between pages and interacting with data.
